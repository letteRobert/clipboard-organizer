# 粘贴板收纳盒

打开 `app\ClipboardHistory.exe` 即可运行。当前成品为 Windows 10/11 x64，使用 Windows 自带的 SQLite，无需额外安装 Python 或数据库软件。切换版本前请在系统托盘退出旧版。

- `app/` 存放成品，`src/` 存放原生 C++ 源码，`legacy/` 存放归档的 Python 版和旧构建文件。
- 项目根目录的 `剪贴板历史.db` 是正式历史数据库。请在原目录打开成品；移动整套项目时请一起移动数据库。
- 新复制的内容保存到当前选中的自建分组。在「全部记录」或「未分组」视图时，新内容保存到「未分组」。可以搜索列表、移动记录、管理分组；确认清空后只删除未分组记录。已进入任意自建分组的文字会清除完全相同的未分组副本。
- 单击记录查看。先在目标软件放好光标，再双击历史记录即可直接粘贴，也可以选中记录后点「粘贴到光标」。点「复制选中内容」则可稍后手动粘贴。
- 「收起」从下方折叠面板。「断开」暂停记录。关闭窗口后可从托盘或 Ctrl+Alt+V 恢复，右键托盘可退出。

## 构建

在项目目录用 PowerShell 运行 `.\build.ps1 -ZigPath 'C:\路径\zig.exe'`。可用 Zig 0.15.2。若 Zig 已加入 PATH，可以省略参数。编译后脚本会运行历史数据库自检，测试旧表结构升级、重复记录、分组、搜索及删除；自检使用内存数据库。
